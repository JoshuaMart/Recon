## The services around Recon

Recon owns the inventory. Scope tracking and scanning live in their own repositories.

| Service | Role |
|---|---|
| [ScopesExtractor](https://github.com/JoshuaMart/ScopesExtractor) | Syncs program scopes from YesWeHack, HackerOne, Intigriti and Bugcrowd |
| [FastRecon](https://github.com/JoshuaMart/FastRecon) | Enumeration, DNS resolution, port scan, HTTP probe. One run, one JSON report |
| Fingerprinter | Browser rendering: technologies, favicon, scripts, cookies, headers, screenshot |
| `certstream-server-go` | The Certificate Transparency feed |

## In and out

| In | Out |
|---|---|
| One user, one instance | Multi-tenancy, roles, invitations |
| Scope synced from ScopesExtractor, plus manual programs | Scraping bug bounty platforms ourselves |
| Discovery on demand, or automatically when a wildcard appears | Periodic discovery runs |
| Periodic verification of what is already known | Vulnerability scanning |
| Technologies from the Fingerprinter only | Technology detection from any other source |
| A few notifications that matter, everything else in the UI | An alert for every change, takeover detection |
